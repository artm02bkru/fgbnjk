# RTSP Viewer + Map

Веб-просмотрщик RTSP/HTTP-видеопотоков **с камер, которыми вы владеете или на
доступ к которым у вас есть разрешение**. Забирает потоки через OpenCV, раздаёт
их в браузер как MJPEG и показывает камеры на карте (Leaflet + OpenStreetMap).

## Возможности
- Один фоновый поток на камеру: камера открывается один раз, сколько бы вкладок
  и превью на карте ни было открыто.
- Авто-переподключение с нарастающей паузой; пока сигнала нет — заглушка
  «NO SIGNAL» вместо зависшего кадра.
- Реальный статус (в сети / подключение / нет сигнала, fps) на карточках и на
  маркерах карты, обновляется каждые 3 с.
- Потоки останавливаются, когда камеру никто не смотрит (`idle_timeout`).
- Кадры ужимаются по ширине и FPS перед раздачей — экономия трафика и CPU.
- URL камер (с логинами/паролями) остаются на сервере: в браузер и на карту
  уходят только имя и координаты.

## Запуск
```bash
pip install -r requirements.txt
cp cameras.example.json cameras.json   # впишите свои камеры
python app.py                          # http://localhost:5000
```
Переменные окружения: `PORT`, `HOST`, `CAMERAS_FILE`.

## Конфиг (`cameras.json`)
```json
{
  "map_center": [55.7558, 37.6173],
  "map_zoom": 13,
  "max_fps": 15,
  "cameras": [
    {"id": 1, "name": "Двор", "url": "rtsp://логин:пароль@адрес:554/stream", "lat": 55.75, "lng": 37.61}
  ]
}
```
`url` может быть RTSP/HTTP-потоком или путём к локальному видеофайлу (для демо).
`cameras.json` в `.gitignore` — реальные адреса и пароли не попадают в git.

## Важно
Подключайтесь только к камерам, которыми владеете или на доступ к которым у вас
есть явное разрешение. Не используйте приложение для доступа к чужим камерам.
